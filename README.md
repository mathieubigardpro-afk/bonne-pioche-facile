# 🍽️ Bonne Pioche Facile

*Vos menus de la semaine, tout simplement.*

La version simplifiée de [Bonne Pioche](https://github.com/mathieubigardpro-afk/bonne-pioche),
pensée pour être utilisable par toute la famille — y compris les personnes peu à l'aise
avec un téléphone : trois onglets, gros textes, explications pas à pas, appairage guidé.

## Comment ça marche

Des plats vous sont proposés un par un : **J'aime**, ou **Non merci**. À deux, chacun
choisit sur son téléphone ; quand un plat vous plaît à tous les deux, c'est un **match** —
il entre au menu tout seul. La liste de courses se prépare automatiquement, rangée par rayon.

- 400 recettes originales, saines et gourmandes
- Le menu de la semaine, jour par jour
- La liste de courses qui se coche en magasin
- Reliez deux téléphones avec un simple code (par exemple `citron-miel-42`) — pas de compte, pas d'e-mail
- Une bascule « Aa · Texte plus grand » pour le confort de lecture
- Fonctionne aussi seul, et même sans réseau (service worker)

## Utilisation

Ouvrir **[l'app en ligne](https://mathieubigardpro-afk.github.io/bonne-pioche-facile/)**,
puis sur iPhone : **Partager → Sur l'écran d'accueil** (sur Android : **⋮ → Ajouter à
l'écran d'accueil**). L'app s'installe comme une vraie application.

## Données

Par défaut, tout reste sur votre téléphone. Si vous reliez deux téléphones, les menus et
la liste de courses passent par une base Google Firebase hébergée en Europe — détail
complet dans [confidentialite.html](confidentialite.html). Aucune publicité, aucun
traceur, aucun compte.
