Bonne Pioche & Bonne Pioche Facile — dernière mise à jour : août 2026

Bonne Pioche est une application familiale de menus de la semaine. Elle est conçue pour fonctionner avec le moins de données possible. Cette page décrit honnêtement tout ce qui est stocké, où, et pourquoi.

Ce que l'application enregistre

  • Vos choix de plats : menus de la semaine, plats aimés, favoris, historique des trois dernières semaines (pour éviter les répétitions).
  • Votre liste de courses : articles cochés et articles ajoutés à la main.
  • Vos réglages : nombre de repas, budget éventuel, taille du texte.
  • Un prénom, si vous utilisez le mode à deux téléphones — celui que vous saisissez, rien d'autre.

Il n'y a ni compte, ni e-mail, ni mot de passe, ni numéro de téléphone. L'application ne demande aucune autorisation (pas de contacts, pas de position, pas de photos).

Où ces données sont stockées

Par défaut : uniquement sur votre téléphone, dans la mémoire locale de l'application. Rien ne quitte l'appareil.

Si vous reliez deux téléphones (mode « Chacun son téléphone »), les données du foyer — menus, choix, liste de courses, prénoms — sont copiées dans une base Google Firebase hébergée en Europe (Belgique, région europe-west1), afin que les deux téléphones voient la même chose. Ce service ne sert qu'à cette synchronisation.

Par ailleurs, les polices de caractères de l'application (Fraunces et Inter) sont chargées depuis Google Fonts au premier démarrage, puis conservées en cache sur votre téléphone. Google reçoit à cette occasion votre adresse IP, comme pour toute page web — aucune autre donnée n'est transmise. Ce sont les deux seuls services tiers utilisés.

L'accès à un foyer est protégé par son code secret (par exemple citron-miel-42). Ne partagez ce code qu'avec la personne de votre foyer : quiconque le connaît peut lire et modifier vos menus.

Ce que l'application ne fait pas

  • Aucune publicité, aucun traceur publicitaire, aucune mesure d'audience.
  • Aucune revente ni partage de données — il n'y a d'ailleurs presque rien à partager.
  • Aucun profilage : les recettes proposées sont calculées sur votre téléphone.

Supprimer vos données

  • Données locales : supprimez l'application (ou son écran d'accueil) et les données locales disparaissent avec elle.
  • Données synchronisées : dans « Notre duo », touchez « Séparer les deux téléphones », puis créez un nouveau code si vous rejouez — l'ancien foyer devient orphelin et peut être effacé sur demande.
